## 🚀 Launch Instructions

### Step 1: Authenticate with GitHub
```bash
# Option A: Using gh CLI
/tmp/gh_2.62.0_linux_amd64/bin/gh auth login

# Option B: Using personal access token
git remote set-url origin https://<TOKEN>@github.com/gpt-computer/gpt-computer.github.io.git
```

### Step 2: Push all commits
```bash
git push origin main
```

### Step 3: Enable GitHub Pages
1. Go to repository Settings → Pages
2. Select "Deploy from main branch"
3. Save

### Step 4: Add Environment Variables
In repository Settings → Secrets and variables → Actions:
- `VITE_GITHUB_TOKEN`: Your GitHub personal access token

### Step 5: Monitor Deployment
- Check Actions tab for workflow runs
- Visit https://gpt-computer.github.io
